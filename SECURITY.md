# Security policy

Use the latest release when possible. Security fixes are prioritized for the latest release and the current default branch.

Please report suspected vulnerabilities through GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is unavailable, contact the repository maintainers privately before disclosing the issue publicly. Do not include API keys, access codes, private conversations, or customer data in reports.

This project is provided without a guarantee that it is vulnerability-free. Self-hosters are responsible for protecting deployment secrets, applying dependency updates, adding shared rate limiting to public deployments, and reviewing provider data-handling terms.
